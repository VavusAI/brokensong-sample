About this sample

This is a working sample built by DCI Brands LLC for Maynooth University's tender PCO 543. It shows how the BROKENSONG online edition would work: it is not the project's website and uses no project data.

How it is built

A build step reads the MEI encodings and the DIAMM source records (through DIAMM's public API) and writes the site as plain files: pages, JSON indexes and the MEI files themselves. There is no database and no application server; the site can be hosted on any static web host and keeps working with no server maintenance. Music is engraved in the reader's browser by Verovio, manuscript images open in Mirador from IIIF image servers, and search and filtering run in the browser from a prebuilt index.

Reconstructed material is encoded with MEI's <supplied> element and shown in a distinct colour, with a legend, wherever the edition displays it.

Listening, commentary and downloads

Every piece can be played in the browser. Verovio reads each note's pitch and length from the MEI at the tempo the encoders set, and a recorded choir sound sings it; the notes light up in the score as they sound, the score follows the music, and each voice can be switched off to hear the others alone. The editors' commentary is read from the MEI header: their editorial method, their notes on the readings, and who encoded and proofread the piece. Bar numbers in the notes are links that open that bar, in that voice, in the edition. Each piece can be downloaded as a PDF score (made by the build step from the same MEI, with the commentary and texts), as MIDI, and as the MEI file itself.
